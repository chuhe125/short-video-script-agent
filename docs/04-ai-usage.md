# AI辅助内容、个人贡献与验证

## 已发生的辅助范围

Codex辅助完成需求拆解、Python标准库实现、合成资料、测试、离线模拟器、真实模型接入、示例与文档。优化中加入编辑brief、预审旁白表达、时间轴、版本失效校验、持续故障处理和Markdown分镜导出。

Codex在本地实际运行29项测试及证据核验，并在用户明确授权发送合成输入/事实/Trace后，用用户本地配置的DeepSeek Flash完成真实模型验收。没有发送原始试卷页面或个人信息，密钥只作API认证，未放入提示词、输出和Trace。

真实协议失败和修复过程均有历史记录，见03-evaluation.md。离线Mock保持mode=mock。DeepSeek在真实模式中选择检索、分镜组合、时长调整、故障后动作和结束；工程检查和编辑启发式由程序执行，不能将这些固定规则都归为模型能力。

本地密钥已放入被.gitignore忽略的.env；.env.example仅保留占位与公共模型配置。曾误填到示例中的密钥不应继续作为公开交付材料；提交前应轮换该密钥并核对提交内容。
