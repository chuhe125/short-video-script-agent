# 用户、目标、范围与成功标准

面向创作者，输入主题、受众、平台、目标时长与风格，从合成产品资料生成可编辑分镜。目标是事实可核对、时长在上限内、风险与失败明确可见。

核心工具为素材检索、分镜写入、时长估算与规则检查。模型根据工具返回选择下一动作；超时长时可以缩短演示停顿、改用更短的事实表达、删减分镜，或明确无法满足。检索为空可以改写查询或请求补充；失败不抹掉已成功的素材与候选稿。

成功标准：

1. 正常输出标题、分镜、旁白/字幕、预计总时长、来源ID、风险和任务状态。
2. 每条旁白属于对应素材的fact或审核表达，来源版本和原文可追溯；不能添加不存在的效果数据。
3. 时长合计不超过目标上限，修改后的稿必须重新通过时长及规则检查；无法满足则incomplete。
4. 缺任一关键字段时needs_input；无素材不编造；工具持续失败仍保留部分产物，不能标成成功。
5. 有执行上限；达到上限返回明确未完成状态。
6. 有至少两条真实模型观察后改变动作的路径，以及正常、信息/资料不足、工具失败的输入输出和Trace。

target_seconds为上限，90%为质量建议，不能用无依据文案或无限空镜填满。受众、平台、风格按明确规则形成编辑brief，真实模型决定具体组合、停顿和修正。

不包含视频渲染、真实TTS、发布、真实媒体识别、任意营销文案的语义事实证明、生产并发Runtime。标准库原生实现符合本题范围，未使用框架。
